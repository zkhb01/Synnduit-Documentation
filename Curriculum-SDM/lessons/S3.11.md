# S3.11 — District Programs

## In one line
The District Programs page is where you **maintain the programs the district offers** and **link each program to the schools that provide it**.

## The idea
A district program is an offering the district runs — an **immersion program**, for example. The District Programs page does two things:

- **Maintain the program records** the district offers (and their supplemental data).
- **Link a program to the schools that provide it.** The link is made here, associating the program with the schools that run it.

This is the other side of the relationship you saw on the Schools page (S3.1): there you connect a *school* to the District Programs it offers; here you maintain the *program* itself and associate it with its providing schools. It's the same association viewed from the program's end.

A concrete CSSD example: the district offers a French **immersion program**. You maintain that program record here, then link it to each school that actually runs immersion — so the program and its schools are tied together.

Like all SDM edits, changes write to DDH with the usual `CreatedBy`/`UpdatedBy` audit trail, so each change is attributable and reversible.

## Why it matters
If you don't know this is where programs are *defined*, you'll look for an "add program" control on the Schools page — but the Schools page only *links* to programs that already exist. The program record itself, and the association of that program to its providing schools, are owned here.

## Watch out for
**Confusing maintaining a program with linking it to a school.** Defining the immersion program — its record and supplemental data — happens here. Saying "this school offers immersion" can be done from either end, but the program itself isn't created on the Schools page; it's maintained on District Programs and then associated with the schools that provide it.

## You've got this when you can…
- State that the District Programs page **maintains the programs the district offers** (e.g. an immersion program) plus their supplemental data.
- Explain that a program is **linked to the schools that provide it**, and that this is the same association seen from the Schools page (S3.1).
- Say that edits write to **DDH** with **CreatedBy/UpdatedBy** audit.
