# L1.1 — What Synnduit is

## In one line
Synnduit is a long-running **data synchronization engine** — it keeps a source and a destination in sync continuously, not a one-time copy.

## The idea
Synnduit is an open-source .NET platform that keeps data in sync between a **source** system (where data originates — HR, PowerSchool, a JSON file, ServiceNow) and a **destination** system (where it needs to land — at CSSD, the **DDH / District Data Hub**). It runs over and over, on a schedule, for the long term.

Its tagline is **"ETL meets version control."** Two halves:

- **ETL** — like a traditional Extract-Transform-Load job, it moves data from one place to another.
- **Version control** — *unlike* a plain copy, it **tracks every change down to the individual field**, and it **remembers the link between each source record and the destination record it created**. Because it remembers that link, the next run *updates* the same record instead of creating a duplicate.

That memory + change history is what makes it a *sync engine* rather than an import script.

## Why it matters
Everything else in Synnduit follows from this. If you think of it as a one-time import, nothing else makes sense — the mappings, the delta detection, the transaction outcomes, the change history all exist precisely *because* it runs continuously and has to avoid duplicating or losing data across runs.

## Watch out for
**"It just copies data over."** Picture a naive nightly script that copies all staff into the destination. Run it twice and you get every record twice — no memory of what it already created, no record of what changed. Synnduit fixes exactly that: it keeps a remembered link (a *mapping*) and a change log, so run two updates the records run one created.

## You've got this when you can…
- Say that Synnduit is a continuous **sync engine**, not a one-time import/ETL tool.
- Explain "ETL meets version control" — it moves data *and* tracks every change + remembers source↔destination links.
- Explain why running a sync twice does **not** duplicate the data.
