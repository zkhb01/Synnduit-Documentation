# L1.2 — Source vs. Destination

## In one line
A **source** is where data originates; a **destination** is where Synnduit makes it land — at CSSD **DDH** is both a destination for feeding systems and a source for consumers.

## The idea
Every sync has two ends:

- **Source** — the system of record where the data is *created and maintained*. At CSSD these include **HRAD** (PeopleSoft HR), **PowerSchool** (School and Student APIs), **ServiceNow**, and **JSON files**.
- **Destination** — the system the data is being kept in sync *into*. At CSSD this is the **DDH (District Data Hub)** — the "single source of truth" that downstream systems read from.

Data flows **source → destination**. Synnduit reads from the source and writes to the destination; it never runs the other way for a given sync.

A few systems can play either role depending on the integration — but within one sync, each end has exactly one job. From the CSSD example (`Sync-SRC-DDH`):

| StarBridge database | Source systems | Destination |
|---|---|---|
| `StarBridge-Hrad`   | HRAD (PeopleSoft HR), JSON, ServiceNow | DDH |
| `StarBridge-School` | PowerSchool (School API) | DDH |
| `StarBridge-Stdnt`  | PowerSchool (Student API) | DDH |
| `StarBridge-AD`  | DDH | Active Directory |
| `StarBridge-AD`  | Active Directory | HRAD |

## Why it matters
"Source" and "destination" are the words every other concept is phrased in: a *feed* reads the **source**, a *sink* writes the **destination**, a *mapping* links a **source** ID to a **destination** ID. If you mix up which end is which, every later concept inverts.

## Watch out for
**Assuming the bigger/more important system is the destination.** Importance has nothing to do with it — the **source** is wherever the data is *authored* (HR owns employee records, so HR is the source even though DDH is the district's hub). At CSSD the destination is frequently the DDH; the variety is on both the source and destination side.

## You've got this when you can…
- Define source (origin / system of record) and destination (where data lands).
- Name the CSSD destination: the **DDH**.
- Classify real systems — PowerSchool, HRAD, ServiceNow are sources; DDH is the destination.
