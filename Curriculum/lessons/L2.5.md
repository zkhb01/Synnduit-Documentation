# L2.5 — Wire it up with MEF

## In one line
Synnduit composes parts with **MEF**: you **export** what you provide with attributes and the engine **discovers** it — there's no container registration to write.

## The idea
You're used to `services.AddScoped<IFoo, Foo>()` (Microsoft.Extensions.DI). Synnduit uses **MEF**, which is attribute-driven: parts are *exported* and *discovered*, not registered in a container (L0.D2).

Three pieces wire a new entity together:

```csharp
// 1) The connectors are already marked — these attributes make them discoverable parts:
[Feed(SourceSystem = typeof(HumanResources))] public class StaffFeed : IFeed<Staff> { ... }
[Sink(DestinationSystem = typeof(SchoolObjectModel))] public class TeamSiteWebPartSink : ISink<TeamSiteWebPart> { ... }

// 2) Publish the service the sink needs as a single shared instance:
[Export(typeof(ITeamSiteWebPartService))]
[PartCreationPolicy(CreationPolicy.Shared)]
public class TeamSiteWebPartService : ITeamSiteWebPartService { ... }

// 3) Tell MEF which constructor to inject into:
[ImportingConstructor]
public TeamSiteWebPartSink(ITeamSiteWebPartService service) => this.service = service;
```

- **`[Feed]` / `[Sink]`** — the engine scans for these and loads your connectors.
- **`[Export(typeof(IService))]`** — publishes a class as the implementation of an interface.
- **`[PartCreationPolicy(CreationPolicy.Shared)]`** — one shared instance (singleton-like), rather than a new one per import.
- **`[ImportingConstructor]`** — the constructor MEF should resolve dependencies into.

Put together: MEF finds the `[Sink]`, sees its `[ImportingConstructor]` needs an `ITeamSiteWebPartService`, finds the matching `[Export]`, and supplies it.

## Why it matters
This is exactly where otherwise-strong .NET devs stumble — they know `Microsoft.Extensions.DI`, not MEF. If the wiring attributes are missing, the part isn't discovered and the integration silently doesn't run.

## Watch out for
- **Expecting a `Startup`/`Program` registration call** — there isn't one; the attributes *are* the registration.
- **Forgetting `[ImportingConstructor]`** — MEF won't know how to build the sink.
- **Omitting `[PartCreationPolicy(Shared)]`** when you meant a single shared service.
