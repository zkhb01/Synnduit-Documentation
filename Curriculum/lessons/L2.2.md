# L2.2 — Implement a Feed

## In one line
A **feed** is the **source connector**: `class XFeed : IFeed<X>` whose `LoadEntities()` reads the source and returns a **full snapshot** of POCOs — the engine does the diffing.

## The idea
You implement the generic interface `IFeed<X>`, binding `<X>` to your entity (L0.G2). From `StaffFeed.cs`:

```csharp
[Feed(SourceSystem = typeof(HumanResources))]
public class StaffFeed : IFeed<Staff>
{
    private readonly HradFactory hradFactory;
    public StaffFeed(HradFactory hradFactory) => this.hradFactory = hradFactory;   // injected (L0.D1)

    public IEntityCollection<Staff> LoadEntities()
    {
        using var context = this.hradFactory.CreateHRAD();
        return context.CCS_HR_AD_SYNC
            .Where(Util.ActiveStaffWithManager)
            .Select(s => new Staff { EmployeeId = s.EMPLID, FirstName = s.FIRST_NAME, /* ... */ })
            .ToList();                                  // materialize before the context is disposed
    }
}
```

Three things to get right:
1. **`[Feed(SourceSystem = typeof(...))]`** marks the class so the engine discovers it (more in L2.5).
2. **`IFeed<Staff>`** — the `<Staff>` is your entity type.
3. **`LoadEntities()`** opens a `DbContext`, queries, **projects** rows into POCOs, and **materializes** with `.ToList()` so the query runs while the context is still open (L0.E1).

You return the whole snapshot every run. You do **not** compute the delta — the engine diffs your snapshot against last run's recorded state.

## Why it matters
The feed is half of every integration. The `.ToList()` and the projection are the two spots people get wrong: skip materialization and you get a disposed-context error; do complex C# inside the LINQ and EF can't translate it.

## Watch out for
- **Returning an un-materialized `IQueryable`** — it executes after the `using` disposes the context → crash. Always `.ToList()`.
- **Doing the delta yourself** — don't filter to "only changed rows"; return everything and let the engine diff.
- **Complex C# inside the LINQ query** — materialize first, then transform in memory.
