# L3.1 — Run a sync and read the console

## In one line
Scheduled runs print to nowhere — **re-run the Run's `.cmd` from a command prompt** to watch it live, and read the **per-segment outcome counts** to see what happened.

## The idea
Runs are scheduled via Windows Task Scheduler, so there's no console to watch. To see live progress, launch the same command yourself — `Synnduit <RunName> <UserSecretGuid>` (the shape from L2.6 / README §5.3, usually wrapped in a `.cmd`).

Each **segment** prints a header and a tally of the **transaction outcomes** from L1.10:

```
Segment 1 out of 2:
Type: Migration   Source system: Power School   Entity type: Section
Loading entity identifier mappings ... 1,097,311 mappings loaded.
Loading source system entities ... 53,243 entities loaded.

Skipped:
No changes detected:        52,108
Changes detected & merged:     431
New entity created:            704
Rejected:                        8
Exception thrown:                0
```

Reading that tally tells you the run's story at a glance: mostly **No changes detected** is a healthy no-op; a wave of **New entity created** is an initial load; any **Exception thrown** needs follow-up (L3.2/L3.5); **Rejected** means an entity couldn't be processed *yet* (often a dependency missing this pass — not an error by itself).

## Why it matters
The console is the fastest triage there is. Before opening StarBridge or the dashboard, a manual re-run tells you whether a run is clean, doing a big load, or throwing — and which segment/entity is involved.

## Watch out for
- **Expecting console output from the scheduled run** — there isn't any; you must re-run manually.
- **Reading "Rejected" as an error** — it isn't; it's "try again later" (e.g. a parent not migrated yet).
- **Ignoring a non-zero "Exception thrown"** — that's the one that always needs a look.

## You've got this when you can…
- Re-run a Run's `.cmd` manually and find the per-segment outcome tally.
- Say what a run did from its counts (clean no-op vs. initial load vs. errors to chase).
